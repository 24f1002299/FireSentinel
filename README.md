# FireSentinel

## Day 2 runtime proof

This repository pins a Windows x86-64 / CPython 3.13.7 OpenCV 5 development
environment in `requirements.lock`. It includes only the packages needed for the
first local vertical slice: OpenCV and NumPy; NetCDF/xarray and PROJ support
for geospatial satellite data; pytest; and Streamlit.

Create the environment and install the platform-specific lock:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install --require-virtualenv -r requirements.lock
```

The `.python-version` file is the required interpreter patch version. This
lock is intentionally scoped to Windows x86-64; resolve a new lock for a
different Python version or platform.

Run the reproducibility checks:

```powershell
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\python scripts\verify_runtime.py
```

The committed reports in `docs/runtime-baseline.json` and
`docs/opencv-build-info.txt` record the verified machine and OpenCV build.
The smoke test hashes cover resize, threshold, morphology, connected
components, and contour extraction. `requirements.lock` is a full, classic pip
lock so it can be installed by the pip 25.2 bundled with CPython 3.13.
`pylock.toml` is the accompanying PEP 751 resolution with artifact hashes,
generated by pip 26.2. Regenerate it, then refresh `requirements.lock` from a
clean environment with:

```powershell
py -3.13 -m pip lock -r requirements.in -o pylock.toml
.\.venv\Scripts\python -m pip freeze | Set-Content requirements.lock
```
