# Responsible use

FireSentinel is a local, historical thermal-evidence review aid. Its outputs
are non-operational and are not for emergency response, dispatch, evacuation,
or public safety decisions.

An anomaly, a persistent thermal region, or a review escalation does not
establish incident type, origin, extent, timing, impact, or cause. Reviewers
must consider independent sources, local context, image quality, alignment,
and the stated data limits before drawing any conclusion.

The system uses fixed cautious outcome states: insufficient evidence, no
persistent evidence, reviewer escalation, human review, or processing failure.
These states describe only the processed thermal evidence and its limitations.
